# GutterCoverageDisplay

**GutterCoverageDisplay** is an IntelliJ IDEA plugin tailored for the Thoughtworks Salesforce Development Team. This plugin seamlessly integrates with the team's pipeline, allowing developers to load Apex code coverage data directly into the IDEA editor's gutter (binding margin). By providing an intuitive and visual representation of code coverage, the plugin enhances the development experience for Salesforce projects.

## Features
- Visualize Apex code coverage data directly in IntelliJ IDEA's gutter.
- Effortless integration with the Thoughtworks Salesforce Development Team's pipeline.
- Boost productivity with instant, in-editor feedback on code coverage.

## Usage
1. Download and install the plugin from the [JetBrains Plugin Marketplace](https://plugins.jetbrains.com/plugin/25087-gutter-coverage-display).
2. Open your local clone of the repository `git@github.com:techops-e2ecs/psa-sfdx.git` in IntelliJ IDEA. **Note:** The plugin is designed to work exclusively within this repository.
3. Navigate to the **Tools** menu and click **Toggle Coverage Data** to enable the plugin.
